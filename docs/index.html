Quick Start

Basic Usage with Zustand

Create a resource slice and start making CRUD operations in seconds.

  • ✅ Auto-generated CRUD functions
  • ✅ Loading states per operation
  • ✅ Error handling built-in
  • ✅ Type-safe by default
store.ts
import { create } from 'zustand';
import { createHttpResources } from 'create-http-resources-slice';

type User = {
  id: number;
  name: string;
  email: string;
};

const useStore = create((set, get) => ({
  ...createHttpResources('user')(set, get),
}));

// Usage in components
const { 
  user, 
  fetchUser, 
  postUser, 
  userLoading 
} = useStore();

await fetchUser();
await postUser({ name: 'John', email: 'john@example.com' });

API Reference

createHttpResources(name, options?)

Creates a resource slice with CRUD operations.

Options

Property Type Default Description
include "all" | HttpMethod[] "all" HTTP methods to include
baseUrl string "" Base URL prefix (e.g., "/api")
isOptimistic boolean false Enable optimistic updates
fetchOptions RequestInit {} Default fetch options

Generated Functions

Function Signature Description
fetch{Resource} (params?) => Promise<TData[]> Fetch all items
post{Resource} (body, options?) => Promise<TData> Create new item
put{Resource} (id, body, options?) => Promise<TData> Replace item
patch{Resource} (id, body, options?) => Promise<TData> Partial update
del{Resource} (id) => Promise<void> Delete item
